This directory contains the output of the analysis:

* **model_training_elevation_US_Fan**: Contains model outputs and causal Shapley values from separate models for each vegetation group across the CONUS, using WTD data from Fan et al.

* **model_training_elevation_US_Fan_oneModel**: Contains model outputs and causal Shapley values from a model fitted across all vegetation groups, used for Figure 4.

* **model_training_elevation_US_globgm**: Contains model outputs and causal Shapley values from separate models for each vegetation group across the CONUS, using WTD data from GLOBGM.
